## Connect your account (no API key in chat)

Paste this into your agent:

```text
Set up AI Video Maker from https://aivideomaker.ai/skill.
Connect my account using browser approval.
Verify setup without spending credits.
```

The agent runs `scripts/connect.mjs`, which prints a **Connect AI Video Maker** link and a comparison code. Open the link, sign in, and approve the matching code. The helper then saves the credential privately outside your project and verifies your account and a sample quote. **No credits are spent.**

- You never paste an API key into chat, code, URLs, or logs.
- No browser available? Run `node <skill-dir>/scripts/connect.mjs --manual` in your own terminal for hidden key entry (keys are created at [aivideomaker.ai › API keys](https://aivideomaker.ai/app/settings/account/api-keys)).
- `AIVIDEO_API_KEY` in the agent's secret environment also works and takes precedence.

## Why this skill: spend guardrails

Letting an agent call a paid API is risky: it can loop, retry, or pick the expensive setting. This skill treats every generation as a billable action:

- **Quote before spend.** `doctor` (setup + balance) and `quote` are non-billable. The agent shows credits and USD before submitting.
- **Hard spending cap.** Generation runs with `--maxCredits <approved limit>`, which is enforced locally and by the API (`X-Max-Credits`). If the quote is higher than the cap, the request is rejected before you're billed.
- **No double charges.** Every submit carries an idempotency key. Retrying the same request returns the original task instead of charging again.
- **Resumable, not repeated.** A polling timeout exits with the existing task ID, and the agent resumes that task rather than creating a new paid one.
- **Refunds on failure.** Credits are refunded when the provider reports a failed generation.
- **Key-level controls.** Per-key daily credit, request-rate, and low-balance limits.
- **Setup is not consent.** Installing or connecting the skill never authorizes a generation.

## Under the hood

```sh
node "$SKILL_ROOT/scripts/run-workflow.mjs" --action doctor                      # setup + balance, free
node "$SKILL_ROOT/scripts/run-workflow.mjs" --action quote --model minimax \
  --payload '{"content":"A cinematic candle on a wooden table","duration":5,"resolution":"720p","tier":"turbo","aspectRatio":"16:9"}'   # free
node "$SKILL_ROOT/scripts/run-workflow.mjs" --model minimax --maxCredits 15 \
  --payload '{"content":"A cinematic candle on a wooden table","duration":5,"resolution":"720p","tier":"turbo","aspectRatio":"16:9"}'   # billable, capped
node "$SKILL_ROOT/scripts/run-workflow.mjs" --action getStatus --taskId <task_id> # resume
```

Exit codes: `0` success, `1` validation/API/job failure, `2` polling timeout with a resumable task ID.
